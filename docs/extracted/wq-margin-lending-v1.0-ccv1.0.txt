References
References allow you maintain additional attribute definitions at the global level like issuer concentration, security concentration and definitions based on deposit tenor. We can also maintain parameters for margin call notice triggers. 
Deposit Tenor LTV: User can define the LTV% (Loanable Value) based on the tenor (residual maturity) of the deposit.
Margin Call Notice Period: The number of days required to generate margin call notice, after customer came into Margin Call/Sell Out.
Security Concentration: Banks can avoid higher exposure to particular security by defining the security concentration.
Issuer Concentration: Banks can avoid higher exposure to particular issuer by defining the issuer concentration.

For example, if the applicable level LTV at global level is say 70% and if we define the LTV at security level as say 60% then the application considers 60% as the loanable value.

Exposure Maintenance
Exposure limits can be maintained in absolute amount for any combination of the following:   
	•	Asset/Sub Asset
	•	Currency
	•	Customer  (Nationality/Residency)
	•	Security
Validations will be done for each of the limits. To facilitate the monitoring of these limits and also to provide an early warning this maintenance allows user to define threshold limits. For example, if the exposure limit in USD is set at 100 million and the threshold limit is 90% system warns the user when the amount breaches 90 million. 

Exposure maintenance is a maker-checker process.

Portfolio Linking
The assets of the customer will be grouped as portfolios. These portfolios will be linked to facility group to form a combination. Multiple portfolios can be linked to multiple facility groups to form a many different combinations. Users will be able to link the portfolios through the portfolio-linking screen. The user will have to select the base first for which the portfolio would have to be linked. 
Following are the types of portfolio linking combinations:
	•	Portfolios linked to the facility group (displayed) of the base.
	•	Portfolio linked to other facility group (or other facility group’s if multiple facility group’s exist) within the same base
	•	Portfolios not linked to any facility group.
	•	Portfolios linked to other base‘s facility group.

Margin Call Process
Margin call process is being tracked at portfolio level. When Customer’s portfolio Exposure exceeds the Top Up amount, the Customer comes into Margin Call. When the Customer’s portfolio exposure exceeds the Sell Out amount, then the Customer comes into Sell Out. In both the cases the customer needs to be intimated so that the Customer can bring in more collaterals value or decrease their exposure. After EOD process, ML module checks all the portfolios and their exposure. If portfolio falls into Margin Call or Sell Out, System generates Margin Call advice, mentioning the short fall amount required to bring the portfolio back to Normal.

List of Facilities
This report shows all the facilities provided for customer portfolio at facility level. It displays facility wise market value of each security, Exposure, NCMV, Status of the Facility, Margin amount required if Facility into margin call/sell out. The market value will calculate based on the blocked quantity at the time of order placement. Blocked quantity will calculate based on exposure, market value and LTV of the security (((MV*LTV %) /Exposure)*Quantity/Nominal). This report can be downloaded into CSV format.

EOD
EOD refers to the end-of-day processes carried out every day to update the margin lending application with data from the product processor or external sources. EOD helps in processing the batch processes for the application. The following two processes are available in the application: 

	•	LTV Logic calculation - Whenever a new attribute definition is created or modified, this EOD needs to executed so as to reflect the latest changes in the system.
	•	Margin Call Process – Whenever any action is performed in the system which might result in change of Customer Status, this EOD needs to be executed to reflect latest statuses.
